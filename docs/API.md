# API покерного сервера

Описание для фронтенда: как создать комнату, посадить игрока за стол и играть по WebSocket.

Коротко о модели. Сервер — единственный источник правды. Клиент только присылает намерения («хочу рейз до 200»), а сервер проверяет правила и после каждого изменения присылает **полное** состояние стола. Его можно просто отрисовать заново, ничего не считая на клиенте. Каждый игрок получает свою версию: свои карты видны, чужие не приходят вовсе (не «скрыты», а именно не отправляются) до вскрытия.

## Запуск бэкенда

Проще всего через Docker, тогда Go ставить не нужно:

```bash
docker compose up --build      # сервер и собранный фронтенд на :8080, остановка — Ctrl+C
```

Или напрямую, если установлен Go 1.27.2 или новее:

```bash
go run ./cmd/server            # слушает :8080
go run ./cmd/server -addr :9000
go run ./cmd/server -static frontend/dist   # заодно отдаёт собранный фронтенд на /
```

Если задана переменная окружения `DATABASE_URL`, сервер хранит комнаты, игроков и историю раздач в PostgreSQL. При старте он сам применяет миграции и восстанавливает комнаты: после перезапуска игроки возвращаются на свои места со стеками на конец последней раздачи. Раздача, которая шла во время перезапуска, пропадает. Без `DATABASE_URL` всё живёт только в памяти. `docker compose up --build` поднимает PostgreSQL сам.

```bash
DATABASE_URL='postgres://poker:poker@localhost:5432/poker?sslmode=disable' go run ./cmd/server
```

### Разработка с Vite: обязательно через прокси

Сервер **отклоняет WebSocket с чужого Origin** (ответ 403). Страница с `localhost:5173`, подключающаяся напрямую к `ws://localhost:8080/ws`, получит отказ. CORS-заголовков у API тоже нет. Поэтому в разработке все запросы идут через прокси Vite, а клиент обращается к своему же адресу (`/api/...`, `/ws`):

```ts
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      "/api": "http://localhost:8080",
      "/ws": { target: "ws://localhost:8080", ws: true },
    },
  },
});
```

`changeOrigin` включать **не нужно**: с ним сервер увидит разные Host и Origin и снова ответит 403. Без `changeOrigin` Host и Origin совпадают, и сервер принимает соединение. Это проверено запросом с такими же заголовками, а сам Vite с этой конфигурацией ещё не запускали.

## HTTP API

Все тела запросов и ответов — JSON. Ошибка всегда выглядит так: `{"error": "текст"}`. Тело запроса не больше 1 КБ. Запросы, которые что-то меняют (`POST`, `DELETE`), принимаются только с `Content-Type: application/json`, иначе 415.

### Аккаунты

Играть можно только с аккаунтом. Сессия — кука `session` (HttpOnly, SameSite=Strict, Secure на HTTPS, Path=/, на 30 дней). Фронтенд её не видит и не хранит: браузер сам отправляет её с каждым запросом и с WebSocket. Сессии хранятся в базе и переживают перезапуск сервера.

**Пользователь** (`User`) — так его возвращают все запросы ниже:

```json
{
  "id": 7,
  "username": "Kerim",
  "balance": 10000,
  "isAdmin": false,
  "bonusAvailable": false,
  "stats": { "hands": 42, "handsWon": 11 }
}
```

`balance` — фишки вне столов. `bonusAvailable` — можно ли сейчас забрать бонус. `stats.hands` — сколько раздач сыграно, `stats.handsWon` — в скольких выиграл хоть что-то.

| Запрос | Тело | Ответ |
|---|---|---|
| `POST /api/auth/register` | `{"username":"Kerim","password":"..."}` | `201` `User` и кука |
| `POST /api/auth/login` | `{"username":"kerim","password":"..."}` | `200` `User` и кука |
| `POST /api/auth/logout` | `{}` | `200` `{"ok":true}`, кука удаляется |
| `GET /api/me` | — | `200` `User` или `401`, если не вошёл |
| `POST /api/me/bonus` | `{}` | `200` `User` с новым балансом |

- Логин: от 3 до 20 символов, буквы (в том числе русские), цифры, `_`, `-`, `.`. Регистр сохраняется для показа, но при входе и проверке занятости не важен: `Kerim` и `kerim` — один логин.
- Пароль: от 8 до 72 байт. Хранится только его хеш bcrypt.
- При регистрации на баланс приходит **10 000** фишек.
- **Бонус:** 1 000 фишек, если баланс меньше 1 000 и с прошлого бонуса прошло 24 часа (или бонуса ещё не было).
- Вход и регистрация с одного адреса — не больше 10 неудачных попыток за минуту, дальше 429.

| Статус | Когда | `error` |
|---|---|---|
| 400 | логин не подходит под правила | `username must be 3 to 20 letters, digits, _ - .` |
| 400 | пароль короче 8 или длиннее 72 байт | `password must be 8 to 72 bytes` |
| 409 | логин занят (при регистрации) | `username is taken` |
| 401 | неверный логин или пароль | `wrong username or password` |
| 401 | запрос, которому нужен вход, без сессии | `log in first` |
| 409 | бонус сейчас недоступен | `bonus is not available` |
| 429 | слишком много попыток | `too many attempts, try again in a minute` |

### Столы

Все запросы о столах требуют входа (иначе 401).

**Стол в списке** (`RoomInfo`):

```json
{
  "code": "K7MQ2X",
  "owner": "Kerim",
  "public": true,
  "smallBlind": 5,
  "bigBlind": 10,
  "minBuyIn": 200,
  "maxBuyIn": 1000,
  "players": 3,
  "maxPlayers": 9,
  "seated": false
}
```

`seated` — сидит ли за этим столом тот, кто спрашивает.

| Запрос | Тело | Ответ |
|---|---|---|
| `POST /api/rooms` | `{"smallBlind":5,"bigBlind":10,"minBuyIn":200,"maxBuyIn":1000,"public":true}` | `201` `{"code":"K7MQ2X"}` |
| `GET /api/rooms` | — | `200` `{"rooms":[RoomInfo...]}` — открытые столы, сначала где больше игроков |
| `GET /api/me/rooms` | — | `200` `{"rooms":[RoomInfo...]}` — столы, где я сижу, в том числе закрытые |
| `GET /api/rooms/{code}` | — | `200` `RoomInfo` — любой стол по коду, в том числе закрытый |
| `POST /api/rooms/{code}/join` | `{"buyIn":500}` | `200` `{"seat":2,"balance":9500}` |

- Создание: `0 < smallBlind <= bigBlind <= minBuyIn <= maxBuyIn <= 1000000`. Создатель за стол не садится сам: после создания фронтенд вызывает `join`.
- `join` списывает `buyIn` с баланса и сажает на первое свободное место. `buyIn` должен быть от `minBuyIn` до `maxBuyIn` и не больше баланса. Если игрок уже сидит за этим столом, `join` ничего не списывает и возвращает его место (`200`).
- Когда игрок уходит из-за стола (сам, выкинули или 5 минут не в сети), весь его стек возвращается на баланс.
- Код комнаты — 6 символов из `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (без 0/O и 1/I). Регистр не важен. Ссылка-приглашение — `/?room=K7MQ2X`.

| Статус | Когда | `error` |
|---|---|---|
| 400 | блайнды или бай-ин вне правил | `need 0 < smallBlind <= bigBlind <= minBuyIn <= maxBuyIn <= 1000000` |
| 400 | `buyIn` вне `minBuyIn..maxBuyIn` | `buy-in must be minBuyIn to maxBuyIn` |
| 404 | нет такой комнаты | `room not found` |
| 409 | на балансе меньше `buyIn` | `not enough chips` |
| 409 | все 9 мест заняты | `table is full` |

### История раздач

`GET /api/rooms/{code}/hands?limit=20`

Последние законченные раздачи, сначала новые. `limit` от 1 до 100, по умолчанию 20. Ответ `200`:

```json
{
  "hands": [
    {
      "hand": 2,
      "board": ["Ah", "Kd", "7c", "7s", "2h"],
      "pot": 400,
      "finishedAt": "2026-10-25T20:01:00Z",
      "players": [
        { "seat": 0, "name": "Ann", "cards": ["As", "Ac"], "bet": 200, "won": 400, "stack": 1195 },
        { "seat": 1, "name": "Bob", "cards": ["Kh", "Ks"], "bet": 200, "won": 0, "stack": 805 }
      ]
    }
  ]
}
```

В `players` только те, кто был в раздаче. `bet` — сколько игрок вложил за всю раздачу, `stack` — стек после неё. `cards` есть только у тех, чьи карты вскрылись на шоудауне, как и в `state`. Без базы данных список всегда пустой.

| Статус | Когда | `error` |
|---|---|---|
| 404 | нет такой комнаты | `room not found` |
| 400 | `limit` не число от 1 до 100 | `limit must be 1 to 100` |
| 500 | не удалось прочитать базу | `could not load hands` |

### Админка

Есть, только если сервер запущен с переменной `ADMIN_PASSWORD`; иначе все адреса `/api/admin/...` отвечают 404. Страница — `/admin` (тот же собранный фронтенд).

- `POST /api/admin/login` `{"password":"..."}` → `{"ok":true}` и кука `admin_session` (HttpOnly, SameSite=Strict, Path=/api/admin, на 12 часов). Неверный пароль — 401. После 5 неудачных попыток за минуту с одного адреса — 429 на минуту. Сессии хранятся в памяти: после перезапуска сервера нужно войти снова.
- `POST /api/admin/logout` — выйти.
- `GET /api/admin/rooms` → `{"rooms":[{ "code", "smallBlind", "bigBlind", "hand", "street", "players": [...] }]}`, по коду. В `players`, как в `state`, свободное место — `null`; у игрока `seat`, `name`, `stack`, `bet` (вложено в текущую раздачу), `connected`, `inHand`, `leaving` и `pendingStack`, если админ поменял стек посреди раздачи.
- `POST /api/admin/rooms/{code}/kick` `{"seat":0}` — освободить место, как будто игрок прислал `leave`.
- `POST /api/admin/rooms/{code}/stack` `{"seat":0,"stack":1500}` — поставить стек от 0 до 1 000 000. Если игрок в раздаче, стек сменится, когда она закончится.
- `DELETE /api/admin/rooms/{code}` — закрыть комнату: все соединения закрываются с кодом 4004 (`room closed`), комната и её история удаляются из базы.

Без входа — 401, нет комнаты или места — 404. `POST`-запросы принимаются только с `Content-Type: application/json` (иначе 415): так чужой сайт не сможет отправить форму от имени админа.

## WebSocket

`GET /ws?room={code}`

```ts
const ws = new WebSocket(`${location.protocol === "https:" ? "wss" : "ws"}://${location.host}/ws?room=${code}`);
```

Игрока сервер узнаёт по куке сессии. Подключиться можно только к столу, где сидишь (сначала `join`).

- Сразу после подключения приходит `state`.
- Нет такой комнаты (неверный код или сервер перезапускали): соединение открывается и тут же закрывается с кодом **4004** и причиной `room not found`. Переподключаться бессмысленно: покажите «Комната не найдена».
- Нет сессии или игрок не сидит за этим столом: соединение открывается и тут же закрывается с кодом **1008** и причиной `log in first` или `not seated`. Нужно войти и/или вызвать `join`.
- Новое подключение того же игрока **заменяет** старое: старое закрывается с кодом **4001** и причиной `replaced by another connection` (игрок открыл стол в другой вкладке или на другом устройстве). После 4001 автоматически переподключаться **не нужно**, иначе вкладки начнут выбивать друг друга. Лучше показать «Вы открыли игру в другом окне» и кнопку «Играть здесь».
- Игрок вышел из-за стола (сам или потому, что слишком долго был не в сети): соединение закрывается с кодом **4002** и причиной `left the table`. Места больше нет, стек вернулся на баланс: верните игрока в меню.
- Одно сообщение не больше 4 КБ. Клиент, который не успевает читать (в очереди больше 16 сообщений), отключается.

Все сообщения — текстовые кадры с JSON. Поле `type` говорит, что это за сообщение.

## Сообщения клиента → сервер

### Ход

```json
{ "type": "act", "action": "raise", "amount": 200 }
```

| `action` | Когда можно | `amount` |
|---|---|---|
| `fold` | всегда в свой ход | не нужен |
| `check` | `options.canCheck` | не нужен |
| `call` | `options.callAmount > 0` | не нужен |
| `bet` | `options.canRaise` и `currentBet == 0` | итоговая ставка на этой улице |
| `raise` | `options.canRaise` и `currentBet > 0` | итоговая ставка на этой улице |
| `allin` | `options.canRaise`, либо когда фишек не больше, чем на колл (`callAmount` равен стеку) | не нужен |

**`amount` — это не прибавка, а сколько игрок поставил на этой улице всего после хода.** Пример: блайнды 5/10, игрок на малом блайнде хочет рейз до 30. Он отправляет `{"action":"raise","amount":30}`, а не 25. Допустимы значения от `options.minRaiseTo` до `options.maxRaiseTo`. Значение `maxRaiseTo` означает олл-ин, и оно разрешено, даже если меньше минимального рейза.

`call` при нехватке фишек сам превращается в олл-ин на всё, что есть. `allin` при нехватке фишек на колл работает как колл.

### Чат

```json
{ "type": "chat", "text": "удачи всем" }
```

Пробелы по краям обрезаются. Длина после обрезки — от 1 до 200 символов.

### Выйти из-за стола

```json
{ "type": "leave" }
```

Если игрок не участвует в раздаче (ещё не вступил, уже закончилась или у него нет фишек), место освобождается сразу. Если участвует, он остаётся до конца раздачи: когда до него доходит ход, сервер сразу сбрасывает за него карты, а после раздачи освобождает место. В обоих случаях соединение закрывается с кодом **4002**.

## Сообщения сервер → клиент

### `state` — состояние стола

Приходит после любого изменения: кто-то сел, подключился или отключился, сделал ход, началась новая раздача. Каждый раз это полное состояние: старое можно просто заменить.

Реальный пример, префлоп, ход Ann:

```json
{
  "type": "state",
  "state": {
    "hand": 1,
    "street": "Preflop",
    "board": [],
    "pot": 15,
    "currentBet": 10,
    "button": 0,
    "toAct": 0,
    "deadline": 1792871962916,
    "you": 0,
    "players": [
      { "seat": 0, "name": "Ann", "stack": 995, "bet": 5, "cards": ["2♥", "Q♠"],
        "inHand": true, "folded": false, "allIn": false, "connected": true },
      { "seat": 1, "name": "Bob", "stack": 990, "bet": 10,
        "inHand": true, "folded": false, "allIn": false, "connected": true }
    ],
    "options": { "canCheck": false, "callAmount": 5, "canRaise": true, "minRaiseTo": 20, "maxRaiseTo": 1000 }
  }
}
```

| Поле | Смысл |
|---|---|
| `hand` | номер раздачи, `0` до первой |
| `street` | `Waiting` (раздач ещё не было), `Preflop`, `Flop`, `Turn`, `River`, `Showdown` |
| `board` | общие карты, 0–5 штук |
| `pot` | все фишки, вложенные в этой раздаче, вместе со ставками текущей улицы |
| `currentBet` | самая большая ставка на текущей улице (нужно, чтобы выбрать `bet` или `raise`) |
| `button` | место баттона, `-1` до первой раздачи и когда игрок с баттона ушёл |
| `toAct` | чьё место ходит, `-1`, если никто |
| `deadline` | до какого момента нужно сходить, Unix-время в **миллисекундах**, по часам сервера. Нет, если `toAct == -1` |
| `you` | твоё место |
| `players` | все места по порядку; свободное место — `null`. Последний элемент никогда не `null` |
| `options` | что можно сделать сейчас. **Есть только у того, чей ход** |

`street == "Showdown"` означает «раздача закончена», в том числе когда все, кроме одного, сбросили карты. Тогда `board` может быть неполным.

Поля игрока:

| Поле | Смысл |
|---|---|
| `seat`, `name` | место и ник |
| `stack` | во время раздачи — фишки **за вычетом** вложенных в банк; после раздачи (`Showdown`) — итоговый стек **с учётом выигрыша** |
| `bet` | ставка на текущей улице |
| `cards` | карты на руках. Свои видны всегда. Чужие — только на `Showdown`, только у не сбросивших и только если до вскрытия дошли двое или больше. Если карт не видно, поля нет |
| `inHand` | участвует ли в текущей раздаче (сел посреди раздачи или кончились фишки — `false`) |
| `folded`, `allIn` | сбросил карты / пошёл ва-банк |
| `connected` | подключён ли сейчас |
| `won` | сколько фишек получил из банка в закончившейся раздаче (включая возврат неуравненной ставки). Нет, если 0 |

Поля `options`:

| Поле | Смысл |
|---|---|
| `canCheck` | можно чекнуть |
| `callAmount` | сколько стоит колл (уже урезано до стека); `0`, если коллировать нечего |
| `canRaise` | можно ставить или повышать |
| `minRaiseTo`, `maxRaiseTo` | границы для `amount` у `bet`/`raise`; `maxRaiseTo` — олл-ин |

Пример на вскрытии (Ann выиграла 20, карты Bob теперь видны):

```json
{
  "type": "state",
  "state": {
    "hand": 1, "street": "Showdown", "board": ["9♠", "Q♦", "2♠", "9♣", "5♣"],
    "pot": 20, "currentBet": 0, "button": 0, "toAct": -1, "you": 0,
    "players": [
      { "seat": 0, "name": "Ann", "stack": 1010, "bet": 0, "cards": ["2♥", "Q♠"],
        "inHand": true, "folded": false, "allIn": false, "connected": true, "won": 20 },
      { "seat": 1, "name": "Bob", "stack": 990, "bet": 0, "cards": ["8♦", "K♣"],
        "inHand": true, "folded": false, "allIn": false, "connected": true }
    ]
  }
}
```

### `chat`

```json
{ "type": "chat", "from": "Bob", "text": "gg" }
```

Приходит всем за столом, включая отправителя.

### `error`

```json
{ "type": "error", "error": "hand is over" }
```

Приходит только тому, чей запрос не прошёл. Состояние стола при этом не меняется. Тексты ошибок рассчитаны на разработчика, а не на игрока: их лучше показывать как общее «ход не принят» и не разбирать. Числа в текстах вида `seat 1, waiting for seat 0: not your turn` — внутренние номера раздачи, а **не** `seat` из `players`. Встречаются:

| Текст (или его конец) | Причина |
|---|---|
| `not your turn` | ход не твой |
| `illegal action` | действие не подходит к ситуации (например, `check` при ставке, `bet` вместо `raise`) |
| `bad amount` | `amount` вне границ `minRaiseTo`…`maxRaiseTo` |
| `hand is over` | раздача уже закончилась |
| `you are not in this hand` | ты не участвуешь в этой раздаче |
| `unknown action …`, `unknown message type …`, `bad message` | неверное сообщение |
| `chat message must be 1 to 200 characters` | пустое или слишком длинное сообщение в чат |

## Карты

Карта — строка из двух символов: ранг и масть.

- Ранги: `2 3 4 5 6 7 8 9 T J Q K A`. **`T` — десятка.**
- Масти: `♣` трефы, `♦` бубны, `♥` червы, `♠` пики (символы Юникода).

## Как идёт игра

- Раздача начинается сама, как только за столом двое или больше с фишками. Подключаться для этого не обязательно: место занимает `join`.
- После `Showdown` следующая раздача начинается через 3 секунды, баттон сдвигается на следующее место с фишками.
- Если фишки остались только у одного, новая раздача не начнётся, и стол останется в `Showdown` последней раздачи.
- **Таймер хода — 30 секунд** (`deadline`). Кто не успел, за того сервер сам чекает, если можно, а иначе сбрасывает. Отключённый игрок остаётся за столом, и за него ходит таймер.
- **Не в сети 5 минут — место освобождается**, как после `leave`. Отсчёт начинается, когда игрок отключился или сел через `join` и не подключился, а также после перезапуска сервера. Подключение отсчёт отменяет.
- Игрок без фишек не вступает в раздачи, но остаётся за столом и видит игру, пока не выйдет.
- Кто сел посреди раздачи, вступает со следующей (`inHand: false` до неё).

## Переподключение

1. Ничего хранить не нужно: игрока узнают по куке сессии.
2. При обрыве связи подключайтесь заново, с паузой (например, 1 → 2 → 5 секунд).
3. После подключения сразу придёт актуальный `state` с вашими картами.
4. Код **1008** — не вошёл или не сидит за столом: отправьте игрока на вход или на экран стола с кнопкой «Сесть».
5. Код **4001** — игрок открыл стол в другом месте: не переподключайтесь сами, только по кнопке.
6. Код **4002** — игрок вышел из-за стола (его стек уже на балансе): верните его в меню.
7. Код **4004** — комнаты больше нет: верните в меню и покажите «Комната не найдена». Переподключаться не нужно.

Итого: переподключаться автоматически нужно при любом закрытии, **кроме 1008, 4001, 4002 и 4004**.

## Известные ограничения

- Нельзя докупить фишки.
- Без `DATABASE_URL` комнаты пропадают при перезапуске сервера. С базой пропадает только раздача, которая шла в этот момент.
- Комнаты удаляются только вручную, из админки.
- `/echo` — учебный эхо-WebSocket, игра его не использует.
